How it works

From the code on the label to a full spec sheet.

Find the code and brand

Every battery label carries a unique code, e.g. 55559, and a brand name. Both are printed right on the sticker — or scan the QR code on the CE label, usually on the rear side of the battery.

2

Enter both above

Type the code and brand into the search box — no app or account needed, it works straight from your browser.

3

Get the full spec sheet

Voltage, capacity, CCA, weight, manufacturer details, safety data and the EU Declaration of Conformity, sourced straight from the manufacturer.
